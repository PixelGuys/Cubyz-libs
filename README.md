# Cubyz-libs
Used to generate precompiled-binaries of the C libraries used in Cubyz:
- [harfbuzz](https://github.com/harfbuzz/harfbuzz)
- [freetype](https://github.com/freetype/freetype/)
- [glslang](https://codeberg.org/Games-by-Mason/glslang_zig/)
- [glfw](https://github.com/glfw/glfw)
- [glad](https://gen.glad.sh/)
- [miniaudio](https://github.com/mackron/miniaudio)
- [stb_image, stb_image_write, stb_vorbis](https://github.com/nothings/stb)
- [Vulkan-Headers](https://github.com/KhronosGroup/Vulkan-Headers)
- [Vulkan-Loader](https://github.com/KhronosGroup/Vulkan-Loader)
- [MoltenVK](https://github.com/KhronosGroup/MoltenVK) (macOS only)
- [Vulkan-Utility-Libraries](https://github.com/KhronosGroup/Vulkan-Utility-Libraries)
- [Vulkan-ValidationLayers](https://github.com/KhronosGroup/Vulkan-ValidationLayers)
- [SPIRV-Headers](https://github.com/KhronosGroup/SPIRV-Headers)
- [cgltf](https://github.com/jkuhlmann/cgltf)
- [Mbed-TLS](https://github.com/Mbed-TLS/mbedtls)
- [TF-PSA-Crypto](https://github.com/Mbed-TLS/TF-PSA-Crypto) (used until release artifacts of Mbed-TLS can be used directly)
- [tinyfiledialogs](https://sourceforge.net/projects/tinyfiledialogs/)
- [VulkanMemoryAllocator](https://github.com/GPUOpen-LibrariesAndSDKs/VulkanMemoryAllocator/)

Issues are tracked on the [main repository](https://github.com/PixelGuys/Cubyz).
